1. 시스템 개요와 접속

경조사 화환 신청부터 업체 발주 안내, 월말 정산까지 한 화면에서 처리하는 시스템입니다. 입력한 내용은 서버에 저장되어 담당자가 바뀌어도 이어서 볼 수 있습니다.

접속 주소https://flower-delivery-dashboard-nu.vercel.app
권장 브라우저크롬(Chrome), 엣지(Edge)
데이터 저장서버 저장. [현황 저장]을 눌러야 반영됩니다
화면이 예전 그대로 보일 때 브라우저가 이전 화면을 기억하고 있는 것입니다. Ctrl + Shift + R 을 눌러 강제로 새로 불러오세요.

2. 로그인

아이디와 비밀번호를 입력해야 들어갈 수 있습니다. 등록되지 않은 아이디는 입장할 수 없습니다.

아이디비밀번호권한
관리자8124전체 기능 (등록·수정·저장·엑셀)
전략구매팀8124전체 기능 (위와 동일)

한 번 로그인하면 같은 브라우저에서는 다음에 자동으로 들어갑니다. 공용 PC에서는 사용 후 [로그아웃]을 눌러주세요.

비밀번호를 바꾸려면 index.html 파일 안의 ACCOUNTS 목록에서 pw 값을 고친 뒤 다시 배포해야 합니다. 화면에서는 바꿀 수 없습니다.

4. 신규 화환 등록

상단 [신규 등록] 버튼을 누르면 등록창이 열립니다. 창 위쪽에서 일반 양식과 BS 양식을 고를 수 있습니다.

양식사용하는 경우입력 항목
일반 양식축하화환, 근조화환, 화분 등 일반 건배송장소/수신자, 문구, 관계(실적 등)
BS 양식임직원 경조사(비에스) 건빈소, 받는분(연락처), 고인, 수량
품목과 양식은 연동됩니다 품목 선택에서 BS_근조화환을 고르면 BS 양식으로 자동 전환되고, 다른 품목을 고르면 일반 양식으로 돌아옵니다. 반대로 [BS 양식] 버튼을 누르면 품목도 BS_근조화환으로 맞춰집니다.

자동으로 채워지는 값

항목기본값
문구(재)FITI시험연구원 원장 윤주경
BS 수량화환,근조기2개,용품
단가품목을 고르면 자동 입력 (수정 가능)

기본값은 그 자리에서 지우고 다시 쓰실 수 있습니다.

등록 절차

  1. [신규 등록] 클릭
  2. 양식 선택 (또는 품목 선택으로 자동 전환)
  3. 거래처명, 발송사유, 발신 문서번호 입력
  4. 배송장소/수신자 입력 — 배송일·시간·장소·수신자·연락처를 줄바꿈해서 적습니다
  5. 부고안내/청첩장 주소가 있으면 붙여넣기
  6. [신규 건 추가] 클릭
  7. [현황 저장]을 눌러 서버에 반영
[신규 건 추가]만으로는 저장되지 않습니다 화면에만 추가된 상태입니다. 반드시 상단 [현황 저장]까지 눌러야 서버에 남습니다.

5. 상세 정보 수정

목록에서 행을 클릭하면 오른쪽에 상세 화면이 열립니다. 수정 후 [저장] → 상단 [현황 저장] 순서로 누르세요.

양식 구분 바꾸기

상세 화면 맨 위 양식 구분에서 일반 ↔ BS를 바꿀 수 있습니다. 잘못 등록한 건을 지우고 다시 만들 필요가 없습니다.

  • BS → 일반으로 바꿔도 빈소·받는분·고인 값은 남아 있어, 다시 BS로 되돌리면 그대로 복원됩니다
  • 양식을 바꿀 때만 필수 항목을 확인합니다
  • 변경 내용은 양식 구분 변경으로 이력에 남습니다

수정할 수 있는 항목

신청일 · 품목 · 단가 · 거래처 · 발송사유 · 발신 문서번호 · 관계(실적 등) · 배송장소/수신자 · 문구 · 부고안내/청첩장 · 상태 · 관리메모 · 담당자

변경 사유 칸에 적은 내용은 변경 이력에 함께 기록됩니다.

카카오톡 안내문 보내기

상태를 배송요청으로 바꾸면 카카오톡 안내 창이 자동으로 열립니다. 이미 배송요청 상태인 건은 상세 화면 아래 [📨 카카오 배송 안내 다시 보내기]로 다시 열 수 있습니다.

  • [카카오톡 전달] — 카카오톡 공유창이 열리고, 보낼 채팅방을 직접 고릅니다. 자동 발송이 아닙니다
  • [안내문 복사] — 내용을 복사해 카카오톡에 직접 붙여넣습니다

안내문은 창 안에서 바로 고쳐서 보낼 수 있습니다.

7. 월말 정산 리포트

목록 아래 월말 정산 리포트에서 업체별 월 집계를 확인합니다. 비에스 계산서 대조와 꽃과향기 실적 확인을 한 화면에서 처리할 수 있습니다.

구분판정 기준용도
비에스품목명에 BS 포함계산서 대조
꽃과향기그 외 전부실적 확인

사용법

  1. 월 선택 상자에서 확인할 달을 고릅니다 (◀ 이전달 / 다음달 ▶로도 이동)
  2. 업체별 건수와 합계 금액을 먼저 확인합니다
  3. 그 아래 품목별 소계로 계산서 항목과 맞춰봅니다
  4. 상세 표에서 건별 내역을 확인합니다
  5. [엑셀 내보내기] 또는 [인쇄]로 보고자료를 만듭니다

비에스 표에는 수량 열이 따로 있어 화환,근조기2개,용품 같은 값을 계산서와 대조할 수 있습니다. 엑셀 파일은 화환_월말리포트_2026-09.xlsx 형태로 저장됩니다.

인쇄하면 리포트만 나옵니다 상단 메뉴, 그래프, 변경 이력은 인쇄에서 자동으로 빠집니다.

8. 저장하기

상단 [현황 저장]이 서버 저장입니다. 저장 중에는 안내 화면이 뜨며, 이때 창을 닫거나 새로고침하지 마세요.

다른 사람이 먼저 저장한 경우 "다른 사용자가 먼저 저장했습니다" 안내가 뜹니다. 내 화면 내용으로 덮어쓰면 상대방 작업이 사라지므로, [서버 새로고침]으로 최신 내용을 받은 뒤 다시 입력하는 것이 안전합니다.

저장이 끝나면 화면 위에 최근 저장 시각과 저장한 사람이 표시됩니다. 저장 전에 이 값을 확인하면 다른 사람의 작업 여부를 알 수 있습니다.

10. 자주 생기는 문제

증상원인과 조치
바꾼 내용이 안 보인다 브라우저 캐시입니다. Ctrl+Shift+R
"조회 전용 계정입니다" 저장 권한이 없는 상태입니다. 관리자 또는 전략구매팀으로 로그인했는지 확인하세요
카카오톡 전달 시 요청 실패 카카오 개발자 콘솔에 접속 주소가 등록되지 않은 경우입니다. 두 곳 모두 등록해야 합니다 (11장 참고)
카카오 공유창이 안 뜬다 브라우저 팝업 차단입니다. 주소창 오른쪽 차단 아이콘에서 허용하세요. 급하면 [안내문 복사]를 쓰시면 됩니다
서버 데이터 불러오기 실패 서버 저장소 연결 문제입니다. 관리자에게 문의하세요
문구가 비어서 나간다 현재는 비어 있으면 기본 문구가 자동으로 들어갑니다. 그래도 비어 있다면 예전 화면을 보고 있는 것이니 새로고침하세요

저장 권한

서버는 저장 요청자 이름이 전략구매팀일 때만 저장을 허용합니다. 화면에 관리자로 로그인해도 서버에는 전략구매팀으로 전달되므로 정상 저장됩니다.

보안상 알아두실 점 로그인 비밀번호는 화면 파일 안에 들어 있어, 마음먹고 보면 확인할 수 있습니다. 외부인의 단순 접근을 막는 수준이며, 서버 자체에 접근 제한은 걸려 있지 않습니다. 개인정보(성명·연락처)가 담긴 시스템이므로 접속 주소를 외부에 공유하지 마세요.
